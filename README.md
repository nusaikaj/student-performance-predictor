# Student Performance Prediction using Machine Learning

This project predicts whether a student will pass or fail using machine learning models.
Logistic Regression and Random Forest algorithms are implemented and compared.

## Features Used
- Study Time
- Attendance
- Previous Marks
- Internet Access
- Extra Classes

## Output
- Pass/Fail Prediction
- Risk Level (Low, Medium, High)
- Feature Importance
- Confusion Matrix Visualization

## Tools
Python, Pandas, Scikit-learn, Matplotlib, Seaborn
